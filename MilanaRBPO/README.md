# PhotoPrint Service

## Тема
Фото-печать: заказ фотографий клиентами с выбором формата и доставкой.

## Основные сущности
- **Customer** — клиент, с именем и уникальным email.
- **Photo** — фотография с названием и привязкой к формату.
- **Format** — формат фото с названием и ценой.
- **Order** — заказ, связывает клиента и выбранные фотографии, может быть оплачен.
- **Delivery** — доставка, создается только для оплаченного заказа.

## Операции сервиса

### CRUD
- Создание, получение, обновление, удаление для всех сущностей:
    - Customer
    - Photo
    - Format
    - Order
    - Delivery

### Бизнес-операции
1. **Создать заказ** с фотографиями для клиента
2. **Оплата заказа**
3. **Создание доставки** для оплаченного заказа
4. **Получение всех заказов** конкретного клиента
5. **Поиск доступных фото** по формату

## Используемая БД
PostgreSQL. Настройки подключения через `application.properties` или переменные окружения.  
Таблицы создаются автоматически с помощью Hibernate (`spring.jpa.hibernate.ddl-auto=update`).

## Тестовые данные
Инициализируются при старте приложения через `DataInitializer`:
- 2 клиента
- 3 формата
- 5 фотографий
- 2 заказа (оплаченный и неоплаченный)
- 1 доставка для оплаченного заказа

## Проверка через Postman
1. Импортировать коллекцию запросов (CRUD + бизнес-операции)
2. Проверять создание заказов, оплату, доставку, поиск по клиенту и фото по формату
3. Примеры тел запросов в JSON включены в коллекцию

## 🔹 Запуск через Docker Compose

1. Создай `.env` файл в корне проекта с переменными для подключения к базе:

```env
DB_URL=jdbc:postgresql://milanarbpo_postgres:5432/milanarbpo_db
DB_USERNAME=postgres
DB_PASSWORD=postgres_password
```

2. Собрать контейнеры:

docker compose build

3. Поднять контейнеры в фоне

docker compose up -d

4. Проверить что бд поднялась

docker exec -it photoprint_postgres psql -U postgres -d photoprint_db
